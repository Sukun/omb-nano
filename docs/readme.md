# docs/ 索引

本目录是 omb-nano 仓库**唯一的"给人读"的文档位置**（`CLAUDE.md` 除外，它留在根目录供 Claude Code 读取）。所有波浪谱算法、固件变更、研究记录都在这里。

## 该跟踪哪一份？

**只需盯 [`2.问题与结论.md`](2.问题与结论.md) 一份**——它是波浪谱算法的权威状态文档，开头有"8 个问题状态总表"，一眼看清每个问题的严重度、状态、解法在固件还是岸上。其它文档按需查阅。

## 文档一览

| 文档                                               | 是什么                                                                                                                                          | 什么时候看                           |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| **[`1.算法说明.md`](1.算法说明.md)**        | 波浪谱算法**怎么工作**：基础概念＋ 采集/处理/上传流程与传回的数据字段 ＋ 逐段数学规范与公式                                               | 看不懂术语、想查某步的精确公式时     |
| **[`2.问题与结论.md`](2.问题与结论.md)** ★ | 算法**有什么问题、多严重、怎么办**：审计发现（对照 SWIFT/NIWA）＋ 仿真定量验证（问题 2/3/4/5/8）＋ 建议。**要跟踪算法可靠性看这份** | 想知道当前状态、做改进决策时         |
| [`固件变更记录.md`](固件变更记录.md)              | 简化版 PCB 的固件改动日志（去铱星、加 SD 卡等）                                                                                                 | 想知道"固件到底改过什么"时           |
| [`研究日志.md`](研究日志.md)                      | 波浪谱相关问题的持续问答日志（Q&A，最新在最上）                                                                                                 | 想回顾某个具体问题当时怎么讨论清楚的 |


## 编号约定

`1.` `2.` 两份编号文档：**编号越大权威性越高**，冲突以 `2.` 为准（例如 `1.` 描述算法现状、`2.` 记录发现的问题与修复状态，若不一致以 `2.` 为准）。`固件变更记录`、`研究日志` 是不同主题的独立/活文档，不参与编号排序。

## 相关但不在本目录
