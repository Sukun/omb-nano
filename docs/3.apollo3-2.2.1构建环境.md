# Apollo3 core 2.2.1 隔离构建环境

本文件记录把固件从 SparkFun Apollo3 core 1.2.1 迁移到 2.2.1 的隔离构建环境。旧的
`Dockerfile` 与 `SparkFun:apollo3:artemis` (core 1.2.1) 流程保持不变；下面的配置是新增的、
独立命名的构建路径，不会覆盖任何历史固件二进制。

## 2. 目标板与链接地址

- FQBN：`SparkFun:apollo3:sfe_artemis_module`（Artemis Module）
- 变体：`SFE_ARTEMIS_MODULE`，`VARIANT_SPI_INTFCS 0`，`VARIANT_WIRE_INTFCS 1`
- 默认加载器菜单 `loader=option_svl`，链接脚本
  `tools/uploaders/svl/0x10000.ld`：`FLASH ORIGIN = 0x00010000, LENGTH = 0x000F0000`
  （960 KiB），与历史 SVL 布局一致。
- 该变体提供本板用到的模块焊盘名 `D5/D6/D22/D25/D26/D27/D28/D42/D43`；
  RedBoard 变体 `SFE_ARTEMIS` 没有 `D43`，因此不能替代。

## 3. 构建命令

在仓库根目录：

```sh
docker build --platform linux/amd64 -f Dockerfile.apollo3-2.2.1 -t omb-nano-apollo3-2.2.1 .
```

编译（`src` 挂载为 `/tracker`，输出与缓存放于仓库内已忽略目录）：

```sh
docker run --rm --platform linux/amd64 \
  -v "$PWD/src:/tracker" \
  -v "$PWD/.apollo3-2.2.1-build/arduino:/tmp/arduino" \
  omb-nano-apollo3-2.2.1 bash -lc \
  'arduino-cli compile -e --output-dir /tmp/arduino/out --build-path /tmp/arduino/build \
     --build-cache-path /tmp/arduino/cache \
     --build-property "compiler.cxx.extra_flags=-MMD -include {runtime.platform.path}/libraries/SPI/src/SPI.h -include /tracker/core_compat.h" \
     -v -b SparkFun:apollo3:sfe_artemis_module .'
```

`compiler.cxx.extra_flags` 是本平台 recipe 实际使用的变量（`compiler.cpp.extra_flags`
在该 platform.txt 中不参与编译）。这两个 `-include` 只解决编译期的 `SPI` 符号可见性，
不改变任何采集或计算逻辑。

## 4. 2.2.1 兼容性改动

| 文件 | 改动 |
| --- | --- |
| `src/params.h` | 用显式 I2C 引脚常量替代 `i2c_port_number`：IMU SDA/SCL = D6/D5，GNSS SDA/SCL = D43/D42（均来自 PCB 网络表） |
| `src/board_control.cpp` | `TwoWire` 改为显式 SDA/SCL 构造；`g_AM_HAL_GPIO_OUTPUT_*` 改为 `OUTPUT` |
| `src/imu_manager.cpp` | 增加 `BurstMode.h`；`pinMode` 使用 `OUTPUT` |
| `src/watchdog_manager.*` | 使用 2.2.1 `WDT` 库的 `wdt`，删除局部 `APM3_WDT` 定义 |
| `src/sleep_manager.cpp` | 用 `analogReadResolution(14)` 替代已删除的 `ap3_adc_setup()/ap3_set_pin_to_analog()` |
| `src/helpers.h`, `src/wave_analyzer.h` | `dtostrf` 头文件路径改为 `api/deprecated-avr-comp/avr/dtostrf.h` |
| `src/iridium_manager.h` | `Uart(1,40,39)` → `UART(40,39)`（同一 UART1 TX/RX 焊盘） |
| `src/params.cpp` | 调试打印改为输出 I2C 引脚 |
| `src/wave_analyzer.cpp` | `arm_rfft_2048_fast_init_f32` → `arm_rfft_fast_init_f32(..., fft_length)` |
| `src/sd_manager.cpp` | 在包含 `SdFat.h` 前定义 `SS`（mbed 桥不提供该宏，默认值未被使用） |
| `src/core_compat.h/.cpp` | 在 `VARIANT_SPI_INTFCS == 0` 时提供惰性 `SPI` 占位对象，仅供未使用的 Adafruit/u-blox SPI 默认参数解析；SD 卡仍走软件 SPI |
