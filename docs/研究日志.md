## [2026-07-02] 浮标每次测量只回传一维垂向加速度谱(array_pwelch[55]+max_value)，不含方向；这条整谱是岸上重建/剔除污染的前提

**Context / Question**
浮标一次波浪测量到底传回什么、是一维能量谱还是带方向的谱？芯片从 IMU 原始采样到打包上传每一步的数据分别是什么？以及既然要靠岸上后处理剔除漂移，是否该额外传一条"不确定性/置信度谱"？

**Reasoning**
逐源码核实的流水线：ISM330DHCX 六轴 IMU @833Hz → 分块均值滤波到 100Hz → Kalman/AHRS 姿态融合（磁力计关闭）出 roll/pitch/yaw+四元数 → 四元数把机体系加速度旋转到 NED 得到 accel_N/E/D → 再分块均值降到 10Hz。关键：`DataEntry` 结构体**只有一个字段 `accel_down`**，第⑤步只存垂向、把北/东两路当场丢弃（=审计问题7），所以谱是**一维垂向加速度**功率谱、**无方向信息**。攒约 20.48 分钟（12288+99 点）后做 Welch（减重力常数→21 段→Hann→FFT→平均）得加速度谱 `working_welch_spectrum`（55 格，0.044–0.308Hz），除 ω⁴ 出 m0/m2/m4→Hs/Tz/Tc，谱峰→Tp；再把 55 格归一化到 `max_value`、量化成 uint16 存进 `array_pwelch[55]`，连同 Hs/Tz/Tc/Tp/max_value/时间戳打包成 `Wave_Packet`，写 SD 卡 WAVES.CSV（本版实际数据汇）+串口（铱星模块未贴装、代码路径空转）。因为 `array_pwelch` 是完整逐格谱、`max_value` 与频格频率已知，岸上可完整重建加速度谱（每格 = `array_pwelch[i]×max_value/65000`）→除 ω⁴ 还原位移谱→重算任意参数。关于"不确定性谱"：稳态低频漂移在 21 个 Welch 段里一致出现，所以"逐格段间方差"这类置信度指标无法把漂移和真实窄带涌浪区分开；而漂移在加速度谱形状上本身就是低频端一个不合理凸起，岸上凭已回传的整谱靠谱形即可识别。

**Conclusion**
浮标回传的是"一维垂向加速度功率谱 + 四个标量海况参数"，不带方向。这条整谱（array_pwelch[55]+max_value）是"岸上剔除污染重算"策略成立的物理前提。对稳态低频漂移**不需要**额外的不确定性谱；真正低成本的增量是①每条记录一个标量 QC 旗标（如最低几格能量占比，标记疑似污染），②仅当瞬态/间歇污染在实测中确成问题时才加"逐格段间方差"通道（数据量翻倍）。本版 PCB 已移除铱星、出口是 SD/串口，字节开销不敏感，但应先用实测数据确认真实污染形态再决定加不加，不提前写死。

## [2026-07-02] 低频漂移(问题2)只污染最低约3-4个频格，可岸上剔除恢复；固件真正需改的是高频端扩展(问题8)

**Context / Question**
问题2（加速度转位移除以 ω⁴、放大低频漂移）在实海到底影响哪个频段、是否波及其他频带、对 Hs/Tz/Tc/Tp 各有多大影响；以及既然浮标回传整条谱，能否在岸上剔除坏频段后恢复干净参数。用最坏情况漂移做补充仿真：正弦漂移 0.0439Hz（=bin9=22.8s，保留带最低点）、幅值 0.15 m/s²，叠加在 typical 风浪（Hs=2m/Tp=8s）上，N=20 相位平均。

**Reasoning**
漂移是单频正弦，其能量在谱上是一条窄线（加 Hann 旁瓣），不像脉冲尖峰那样全频段扩散。实测逐 bin 污染：只有 bin 9-12（周期 17-22.8s）被显著抬高，bin 13（15.8s）已基本干净（1.05×），bin 14 及以上（≤14.6s）完全不受影响（1.00×）。ω⁴ 换算对同一 bin 在 clean 与 drift 间相同、会在比值里抵消，所以加速度谱与位移谱的逐 bin 污染比值完全一致——证明污染是纯加性且局部。对参数：Hs +166%（m0 被 ω⁻⁴ 放大的低频主导）；Tz +114% 偏长（m0 暴涨但 m2 因 f² 加权受影响小，√(m0/m2) 被拉长）；Tc +22%（f²/f⁴ 加权压低低频贡献但没压尽，仍超 0.5s 阈值）；Tp −0.4% 几乎免疫——因为问题6 当初把 Tp 定义为取**加速度谱**峰值，而加速度谱上漂移只是小尖、压不过真实风浪峰（加速度谱因 ω² 加权偏袒高频）。岸上恢复：浮标回传 `array_pwelch[55]`（完整逐 bin 加速度谱，量化）+ `max_value`，bin 频率固定已知，故可完整重建加速度谱 → 除 ω⁴ → 位移谱。实测从有漂移的传输谱丢掉最低 3 格（bin 9-11）后重算，Hs/Tz/Tc/Tp 全部恢复到干净值（+0.2%），且因该风浪在 17-22.8s 本无真实能量，剔除零损失。

**Conclusion**
低频漂移是"局部、可逆、岸上可修"的问题：污染只到 bin12(17.1s)、中高频全干净、Tp 天然免疫，而浮标回传整条谱使"岸上剔除坏格重算"可行（丢 bin 9-11 即完全恢复）。战略上：①问题2 不必在固件里做截断或高通，降级为岸上后处理（自适应检测低频端异常尖峰、动态剔除，比固定截断更稳健）；②固件真正必须改的是高频端扩展（问题8，welch_bin_max 64→103 抓 2-3.25s 短波）——那部分谱固件不算就永远没有、岸上无法补救；③没必要继续压低周期上限（16.7s 截断已在污染区上沿，再压只白丢真实中周期能量）。重要前提：机上算的 Hs/Tz/Tc 是全（含污染）频段结果，有漂移时不可信，权威值须岸上从谱重算；Tp 机上值已可信。待真实数据确认：真实 IMU 漂移主要落在什么频率（热/倾斜漂移通常 <0.02Hz、会被 Hann 窗直接滤掉几乎无害；0.04-0.06Hz 的压力测试偏人为），需水池/现场静置数据实测一条真实漂移谱。
